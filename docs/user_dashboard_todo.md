## Щодо розташування розділів

1. **Гараж користувача**: 
   - Відображати на головній сторінці кабінету користувача.
   - Додати кнопку для додавання та видалення транспортних засобів.

2. **Список записів**:
   - В окремому розділі "Appointments".
   - Фільтри та кнопки для скасування записів.

3. **Контактна інформація**:
   - В окремому розділі "Profile" або "Contact Info".
   - Поле для номера телефону та кнопка верифікації.

4. **Premium & Referrals**:
   - В окремому розділі "Premium & Referrals".
   - Відображення реферального коду та статусу преміум.
   - Інформація про знижки та бонуси.
